# Alex Bell Arts branding

Source: owner-supplied `4x.zip` artwork, replacing the earlier `1x.zip` versions. ABA means Alex Bell Arts.

Implemented supplied secondary wordmark and light/dark favicon artwork without tracing or modifying the images. Public assets are under `public/brand`. The shared BrandMark component renders the actual logo across the welcome, sign-in, owner/client workspace and demonstration. Accessible text identifies Alex Bell Arts.

Palette sampled directly from the supplied Colour Palette PNG:
- Hyper Purple: #7E00E5
- Acid Lime: #D4E600
- Carbon Black: #111111
- Stark White: #F9F9F9

Purple/white is used for primary actions; lime is a restrained accent, not low-contrast body text. Neutral/purple tints replace temporary green interface colours. Fictional client project artwork retains its own example design identities.

The uploaded typeface sheets are raster samples, not font files or documented font names. Existing readable fallbacks remain; exact typography needs the font names/files and appropriate licences.
